# Claw support

Claw runs compatible games that you supply from Files. It does not include games or console files.

## Importing games

Open **Library → Import** and choose a supported game from Files. Claw accepts decrypted 3DS `.cia`, `.cci`, `.3ds`, `.cxi`, and `.app` files and `.3dsx` homebrew; DS `.nds`; GBA `.gba`; Game Boy `.gb`; Game Boy Color `.gbc`; and NES `.nes`. A `.7z` or `.zip` archive containing one supported game can also be imported. Large files from a cloud file provider may take time to download before unpacking begins.

If an archive cannot be opened, extract it in Files or another archive app and import the supported game file inside. Encrypted games and unsupported archive methods cannot be imported. Only import files you have the right to use.

## Saves and controls

Use each game's own save menu for regular progress. Save states and control-layout options are available from the in-game menu. You can export saves and system data with the iOS share sheet; review the export before sharing because it may include console keys.

## Help and privacy

For support, email [feedback@salamlabs.io](mailto:feedback@salamlabs.io?subject=Claw%20support). Include the iPhone model, iOS version, Claw version, game system, and a description of the problem. Do not send commercial game files, console keys, or private save data.
