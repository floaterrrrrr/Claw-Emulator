Build and upload
4. Use a released Xcode accepted for App Store uploads. Verify the toolchain
   used for the exact archive selected for release.
5. Run bash Scripts/check-build.sh, then bash Scripts/archive-app-store.sh.
   For compilation without signing, use the archive script's --unsigned flag.
   The App Store archive explicitly uses generic ARM64 instructions; do not
   distribute the developer-only latest/A15-optimized IPA to all iOS 17 devices.
   Device and Apple Silicon Simulator dependencies are rebuilt from the pinned
   source manifest for iOS 17. The archive validator checks actual Mach-O
   deployment versions, including embedded frameworks. The completed local
   signed archive has no linker warnings about newer-iOS dependencies.
6. In Xcode Organizer validate the signed archive and upload, or upload the
   exported IPA using Apple's Transporter. Local export does not upload it.
   Increment App/Info.plist's CFBundleVersion and synchronize the metadata draft
   before uploading another build.
   Run python3 Scripts/validate-app-store-archive.py to check the actual archived
   identity, iPhone target, required resources, executable, and debug symbols.
7. Test the actual signed build on supported iPhones through TestFlight.
   Check fresh launch/import, large game import, audio/controllers, saving and
   loading, background/resume, rotation, low memory, and export. Include older
   supported iOS 17 devices, not only the newest phone. Simulator/mock-core
   tests cannot establish playable emulator performance.
